Estimasi waktu online untuk aturan server “jaga property minimal 1 jam dalam 14 hari”. Paus otomatis saat game alt-tab atau AFK.

Ledger Uang Harian

Cash & bank dari /stats, plus pemasukan/pengeluaran per hari dari semua job secara otomatis.

Silent Fetch

Ambil /stats, /paychecks & /mp secara senyap — dialog tidak pernah muncul di layar game.

Terjemahan Chat (AI)

Terjemahkan chat masuk/keluar dengan Ollama, Gemini, Libre, OpenRouter, atau Groq. Punya gaya custom per arah percakapan.

Media & Lirik Tersinkron

Tampilkan lirik karaoke yang tersinkron + pemutar video YouTube/Vimeo di dalam notch, tanpa keluar dari game.

Multi-Karakter

Satu akun SA-MP bisa main banyak karakter. Setiap data game tersimpan rapi per karakter dan berpindah otomatis saat ganti karakter.

Bagaimana cara kerjanya

NotchClone membaca chatlog SA-MP dan memanfaatkan ASI plugin untuk fetch data secara senyap — tanpa injeksi yang berbahaya.

1

Baca chatlog.txt

Semua event game (gaji, jual, shift taxi, repair) dianalisis dari chatlog SA-MP secara real-time, lalu diagregasi per hari.

2

Fetch senyap via ASI

/stats, /paychecks & /mp diambil lewat dialog yang ditelan — tidak pernah mengganggu tampilan game.

3

Render jadi notch elegan

Semuanya tampil di bilah transparan always-on-top yang membesar saat disentuh kursor, lalu mengecil kembali saat kamu kembali main.

Persyaratan & Cara Instalasi

Dibangun dengan Electron. Ringan, portabel, dan mudah dijalankan.

OS

Windows 10 / 11

Overlay memakai DWM composition Windows (win32).

Game

GTA San Andreas

SA-MP / open.mp client (gta_sa.exe) dengan chatlog aktif.

Runtime

Electron 38

Node.js untuk build dari sumber. Binary sudah pre-built.

Jalankan dari sumber

Clone repo lalu install dependency dan jalankan Electron.

$ npm install
$ npm start
$ npm run dev # mode developer

Untuk build distribusi: electron-builder atau package manual folder poni-clone/. Jalankan poni.exe untuk hasil build yang siap dipakai.

Siap main lebih terorganisir?

Pasang NotchClone, arahkan kursor ke bilah di atas layar, dan biarkan ia mencatat detail yang biasanya kamu lewatkan.
